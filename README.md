# 🥤 스포츠스태킹 토너먼트 매니저

학교 체육관 **빔프로젝터**로 실시간 대진·결과를 발표하기 위해 만든 스포츠스태킹 대회 운영 시스템입니다.

**라이브 사이트:** https://thehuihuifam.github.io/tournament-manager/

## 주요 기능

- **6개 종목 프리셋** — 개인 `3-3-3` · `3-6-3` · `사이클`, 더블 `더블 3-3-3` · `더블 3-6-3` · `더블 사이클`
- **참가자 등록** — 이름 + 성별(남/여), 개별 등록 / 목록 일괄 붙여넣기 (번호·이름·성별, 탭/공백/쉼표 구분)
- **더블 팀 빌더** — 성별 필터(전체/남/여), **남-남·여-여 자동 페어링(1클릭)**, 무작위 페어링, 드래그/클릭 수동 조립, 팀 순서 = 시드
- **3인 더블 팀 (홀수 인원 처리)** — 기본 2인 팀이지만 홀수 인원이면 자동으로 3인 팀을 구성해 leftover 0명.
  3인 팀은 하나의 팀·하나의 시드로 브래킷에 오르고, 한 팀 안의 세 2인 조합(AB · BC · AC)이 경기마다 순서대로 출전.
  조합 순서는 생성 시 확정·저장되고(새로고침에도 유지), 버튼으로 다시 섞을 수 있으며, 매치 카드와 프로젝터 Now Playing에 현재/다음 출전 조합이 표시됨
- **공정한 부전승(BYE)** — 팀 수가 2^n 이 아닐 때 표준 시드 방식으로 상위 시드에게 BYE 자동 배치 (BYE-BYE 매치 불가증)
- **기록 입력** — 스태킹 공식 **타이머(초.밀리초, 짧은 기록 승리)** 또는 **세트(승패)** 방식, 동률·수동 승자 지정 지원
- **반응형 전파 + 안전 롤백** — 승자 결정 시 다음 라운드 자동 진출, 점수 수정/결과 초기화 시 하위 라운드 결과가 확인 후 안전하게 초기화
- **📺 빔프로젝터 발표 모드** — 상단 노란 버튼(또는 전체화면)으로 전환. 네비게이션·편집 UI를 모두 숨기고
  Now Playing(현재 경기) + 전체 대진표를 초고대비·대형 글씨·굵은 대진선으로 스크린 전체에 표시. ESC로 종료
  - **라이트 테마 기본 + ☀️/🌙 전환** — 밝은 체육관에서도 잘 보이는 흰 배경/진한 글씨가 기본값이고,
    상단 바의 테마 버튼으로 다크 테마와 전환합니다. 선택한 테마는 LocalStorage에 저장되며,
    테마 정보가 없는 기존 저장 데이터는 라이트로 자연스럽게 이관됩니다.
  - **Now Playing 이름 한 줄 표시** — 2~10글자 이상 한글 이름도 글자 단위로 끊기지 않고(keep-all)
    카드 폭·화면 높이에 맞춰 한 줄로 표시되며, 이름/점수 영역에 스크롤바가 생기지 않습니다.
  - **🔀 출전 조합 순서 랜덤 섞기** — 3인 팀이 포함된 경기에서 Now Playing(프로젝터)과
    매치 카드 푸터(편집 화면)에서 조합 순서를 다시 섞습니다. (2인 팀만 있는 경기에는 버튼이 없습니다)
- **🎲 대진 무작위로 다시 섞기** — 종목별 대진 보드의 상태 표시줄에서 확인 절차를 거쳐
  무작위 배치로 대진표를 재생성합니다. 부전승(BYE)은 매치마다 하나씩 균등하게 분산됩니다.
- **반응형 UI (모바일·PC)** — 휴대폰에서는 헤더/단계 탭/팀 빌더가 세로로 재배치되고,
  입력창 확대(iOS)와 가로 스크롤이 발생하지 않습니다. 프로젝터 화면은 가로 화면(16:9·4:3)에서
  2열, 세로/모바일에서는 Now Playing → 대진표 순서로 쌓여 표시됩니다.
- **LocalStorage 영속화** — 새로고침/브라우저 종료 후에도 명단·대진·진행 상태 유지 (기존 v1 명단 자동 이관)

## 개발

```bash
npm install
npm run dev       # 개발 서버 (Vite, 소스 루트: web/)
npm run build     # 타입체크 + 프로덕션 빌드 (dist/ 출력)
npm run typecheck
```

- 소스: `web/` (React + TypeScript + Vite)
- 브래킷 알고리즘: `web/src/bracket.ts` (시드 패턴, BYE 배치, 승자 전파/롤백, 페어링)
- 빌드: `base: './'` 상대경로 — GitHub Pages 서브패스(`/tournament-manager/`)에서 바로 동작

## 배포 (GitHub Pages)

1. `main` 푸시 시 `.github/workflows/deploy.yml`이 빌드 후 `dist/`를 `gh-pages` 브랜치로 배포합니다.
2. GitHub Pages 소스는 `gh-pages` 브랜치로 설정되어 있습니다.
3. (폴백) 빌드 산출물(`index.html`, `assets/`)이 저장소 루트에도 커밋되어 있어,
   Pages 설정이 legacy(main 루트)로 되돌아가도 사이트가 그대로 동작합니다.
